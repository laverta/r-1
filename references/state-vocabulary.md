# 状态词汇表（照见用）

> 状态会来会走，人不是状态的集合。全部标签 `metaphor` 级；"近邻科学"列仅标定相似性（evidence 级才有外部依据）。

| 状态词 | 体验描述 | 近邻科学 |
|---|---|---|
| 启动摩擦 | 万事开头的那堵墙——事不难，启动难 | 任务切换成本 / 临床"启动"问题（evidence） |
| 过载 | 同时持有的约束超过容量，开始丢球 | 工作记忆容量（Cowan 4±1，evidence） |
| 失焦 | 主线程被局部细节或内部噪声劫持 | 注意控制理论 / goal neglect（evidence） |
| 过拟合 | 旧解适配旧环境，环境一变就崩 | 压力下目标导向→习惯切换（Schwabe & Wolf，evidence） |
| 温度失衡 | 高温=想法发散收不住；低温=僵住动不了 | Yerkes-Dodson 倒 U（evidence） |
| 奖励模型错价 | 明知重要却启动不了——努力的定价失真 | effort discounting（Salamone，evidence） |
| 噪声坍缩 | 脑内多个主张一起叫，没有调度 | —（metaphor） |
| 单透镜捕获 | 一个模式吞掉所有输入，万物归于一式 | 确认偏误强形式（evidence） |

## 使用规则

1. **默认说人话**。只在对方伸手要这套语言时才给，给时轻标注：`[机制翻译]`。羞耻翻译（对判定语的即时转译）不受此条约束——它是核心动作，判定语出现即触发，见 SKILL.md。
2. 高唤醒或脑雾状态：放下词汇表，给平实具体的步骤。词汇是给有余力照镜子的人的。
3. 翻译成机制 ≠ 解释了成因。所有词条都是描述形状，不是断言硬件。
4. 光谱声明随表携带：普适状态，ADHD 是远端，标签描述状态不描述人。
