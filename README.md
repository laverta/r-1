# R-1 · 重连（Rewire-One）

> 前身：mindharp（2026-08，归档于 D:\mindharp）。这不是修补，是重构。

## 定位

面向 ADHD/AuDHD 的自我理解与重构体系：**理解 → 接纳 → 重构**。

- 理解：把"懒/不专注/不努力"翻译回机制语言（启动摩擦、带宽、奖励模型错价）
- 接纳：羞耻从等式里拿掉——状态是普适的，ADHD 是光谱远端，状态描述不等于人的定义
- 重构：外部脚手架 + 长线的模式截断，不靠意志硬扛

## 命名三层内核

1. **Rewire（重新布线）** 对应神经可塑性——"rewire your brain" 是全球 ADHD 群体高度共鸣的概念，硬核无鸡汤。
2. **体系对称**：T-1（观测端·镜子）↔ R-1（落地端·刻刀），同属一号体系。T-1 提供元认知方法，R-1 落地为自我重建。
3. **重连三关**：重新连接神经通路；重新和真实的自己联结；断开旧的代际模式复制链。

## 给谁

任何人。状态是普适的。对 ADHD/AuDHD 同胞尤其贴合——尤其给长期被说"懒""不专注""不努力"的人。

## 安装

所有文件只放 D 盘：作为工作区级技能，放入使用它的工作区目录（`<workspace>/.zcode/skills/` 或 `<workspace>/.agents/skills/`）。不复制到 C 盘。首次使用建议读 `FOREWORD.md`——注意它是个人叙事，仅存本地，永不上传。

## 边界

不诊断、不开药、不替代专业治疗；危机响应归模型；所有框架 metaphor/hypothesis 级无医学依据。详见 `references/safety.md`。
